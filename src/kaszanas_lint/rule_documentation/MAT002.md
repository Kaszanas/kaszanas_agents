# MAT002: if/elif chain that is really a dict lookup

Derived from the **python-match-statements** standard. Fix: **none** (report only).
Works on any Python version.

## What it does

Flags if/elif chains of at least `min-match-branches` branches where:

- every test compares one subject to a literal or dotted constant (`==`, `in (...)`,
  `or`);
- every body is a single `return <constant>`, or a single assignment of a constant to
  the same variable.

## Why is this bad?

The chain encodes a table as control flow. A dict states the mapping as data, and a dict
lookup is **constant time**. if/elif and `match` both test the branches one by one, so
lookups for later branches get slower. In the
[benchmarks](../../../docs/benchmarks/match-statements.md), a dict lookup takes about 27
ns at any position. A 7-branch if/elif or `match` takes about 50 ns for the last branch
and for a miss.

## Example

```python
def status_text(code):
    if code == 200:
        return "OK"
    elif code == 404:
        return "Not Found"
    elif code in (500, 503):
        return "Server Error"
    else:
        return "Unknown"
```

Use instead:

```python
STATUS_TEXT = {200: "OK", 404: "Not Found", 500: "Server Error", 503: "Server Error"}


def status_text(code):
    return STATUS_TEXT.get(code, "Unknown")
```

## Fix safety

There's no automatic fix. Where the table lives (module constant, class attribute), what
it's called, and how the default is handled are design decisions.

Watch out for one semantic difference: dict keys are hashed. `1`, `1.0` and `True` are
the same key, as they are under `==`. But a lookup with an unhashable subject raises
`TypeError`, where the if/elif chain would fall through to `else`.

## When it is not reported

- Any branch has more than one statement, or a non-constant value: `return compute(x)`,
  or assignments to different variables.
- Tests use class patterns, `is None`, or guards (`x == 1 and ready`).
- The chain is shorter than `min-match-branches`.

## Configuration

```toml
[tool.kaszanas-lint]
min-match-branches = 3
```

Suppress one chain with `# noqa: MAT002` on its `if` line.
