# KWA001: positional arguments in a call to a project-defined callable

Derived from the **python-keyword-arguments** standard. Fix: **always available** when
reported with `[*]`.

## What it does

Flags calls to functions, methods and classes **defined in your project** that pass
keyword-capable arguments positionally, and rewrites them to use keywords.

## Why is this bad?

- A call site such as `create_user("ada", "ada@example.com", True)` can't be read
  without opening the definition.
  `create_user(name="ada", email="ada@example.com", is_admin=True)` documents itself.
- If two arguments of the same type are swapped, the positional call still runs. The
  keyword call makes the mistake visible in review.
- Reordering or inserting parameters silently rebinds positional calls. Keyword calls
  keep working, or fail loudly.
- Coding agents editing a call they can't fully see are far less likely to misplace a
  keyword argument.

## Example

```python
def area(width, height): ...


area(2, 3)
```

Use instead:

```python
area(width=2, height=3)
```

## Fix safety

The fix inserts `name=` before each positional argument, using the real parameter names
from the definition.

- **It's safe**: only calls whose target and signature are known for certain are
  reported as KWA001.
- **It handles awkward layouts**: redundant parentheses, lone generators
  (`f(name=(x for x in y))`), walrus arguments (`f(name=(x := g()))`), comments, CRLF
  line endings and BOMs.
- **It's checked**: every fixed file is re-parsed before it's written.

## When it is not reported

Positional arguments stay allowed where keywords are impossible:

- parameters before `/` (positional-only);
- arguments that land in `*args`;
- calls that unpack `*iterable`;
- the explicit `self` in `ClassName.method(instance, …)`.

A call isn't treated as project-defined (only [KWA002](KWA002.md) applies) when:

- it uses an unknown decorator (which may change the signature);
- it uses an `@overload`;
- a property is involved;
- the class has a custom metaclass or a `__new__`;
- an external base class could override the method first;
- the name is re-bound or shadowed;
- it's a star import from external code.

## Configuration

```toml
[tool.kaszanas-lint]
allow-positional = 0                    # leading positional arguments tolerated
extend-safe-decorators = ["my_project.tracing.traced"]
per-file-ignores = { "tests/**" = ["KWA001"] }
```

Suppress one call with `# noqa: KWA001` on its first or last line.
